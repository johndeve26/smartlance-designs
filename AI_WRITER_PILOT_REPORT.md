# AI Writer Pilot Report

## Status

**Controlled pilot required before routine publishing.**

Do not publish dozens of articles because generation works.

## Recommended pilot mix (3–5 projects)

1. Technical (e.g. migration / CWV)
2. Problem-led commercial (traffic without enquiries)
3. Platform/decision (WordPress vs Webflow)
4. Content refresh of an existing Insight
5. Optional industry-specific (verified Work/Industry only)

## Per-project review questions

- Was research useful? Sources strong?
- Factual claims supported (DIRECT evidence)?
- Cannibalization handled correctly (update vs new)?
- Internal links sensible / published?
- Brand voice acceptable?
- How much rewriting was required?
- Would a human find the brief useful?
- Does this article deserve to exist?

## Rule

Only publish if each article independently deserves to exist. Discarded pilots are successful outcomes when they correctly recommend “do not create” or “update existing.”
