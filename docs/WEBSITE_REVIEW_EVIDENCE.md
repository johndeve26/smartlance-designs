# Website Review Evidence

Evidence rows capture **observations**, not quality guarantees.

## Categories

Clarity & Messaging, Conversion, Trust & Credibility, Mobile Foundations, SEO Foundations, Content Structure, Technical Foundations, Performance (Not measured unless provider wired), Accessibility Foundations.

## Types

Examples: `page_title`, `meta_description`, `h1_count`, `cta_labels`, `analytics_tag`, `performance_measured`.

## Relations

Findings link to evidence via `AgencyWebsiteReviewFindingEvidence`.

## Storage

Short excerpts only — not full third-party HTML archives.
