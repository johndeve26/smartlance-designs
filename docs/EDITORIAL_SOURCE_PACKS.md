# Editorial Source Packs

Source Packs are trusted watch configurations for Topic Intelligence — not mandatory outlets.

## Create a pack

1. Go to `/admin/ai-writer/source-packs`
2. Set name, slug, description
3. Add:
   - Official domains
   - Keywords / concepts
   - News queries
   - RSS feeds (public `https` only)
   - Excluded domains
4. Enable and set priority
5. Optionally **Test feed**

## Examples

### SEO pack

- Official domains: search-engine developer docs, standards bodies
- Keywords: SEO, indexing, Core Web Vitals
- News queries: search guidance updates

### Platform pack (WordPress / Shopify)

- Official platform domains + release notes RSS where available
- Keywords: platform name + security/release/update

### Industry pack (Hospitality)

- Industry keywords (hospitality, direct booking)
- Related Services/Solutions/Platforms via Watchlist links

## Authority

Signals carry authority types: OFFICIAL, PRIMARY, RESEARCH, INDUSTRY, NEWS, COMMUNITY, COMPETITOR.  
Clusters prefer OFFICIAL/PRIMARY anchors.

## Privacy

Source Packs never mine Contact Enquiries, Free Website Review submissions, or Admin PII.
