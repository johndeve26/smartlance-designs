# Editorial Strategy Calibration

Qualitative guidance from Topic Intelligence V1 calibration. **Not** immutable algorithm rules.

## Current content imbalance (observed pattern)

Strong / over-indexed editorial themes historically:

- Short-term rental / hospitality marketplace independence  
- PriceLabs / dynamic pricing  
- Calendar sync / double booking  

Weaker relative editorial depth (commercial pages often exist):

- Conversion / CRO diagnostics beyond a few Insights  
- Website performance for business owners  
- Migration SEO process depth  
- Local SEO for service businesses  
- Platform decision Comparisons beyond a few pairs  

Article count ≠ authority. Prefer one strong Guide/Comparison/Case Study over many thin near-duplicates.

## Priority authority areas

Align with Admin **Topic strategy settings** when present. Initial strategic themes that should remain visible:

- Website Design / Redesign  
- Website Development  
- SEO / Local SEO  
- Conversion  
- Website Performance  
- E-commerce  
- Website Migration  
- Website Strategy  
- Platforms (WordPress, Webflow, Shopify, BigCommerce, etc.)  

Strategy weighting may raise priority but **must not** override:

- cannibalization  
- poor evidence  
- lack of unique value  

## Intentionally deprioritized

- Commodity listicles (“10 reasons…”, “ultimate guide”, year-bait importance)  
- Unrelated viral / celebrity / stock chatter  
- Near-identical STR angles already published  
- Competitor coverage alone without Smartlance angle  
- Vague AI-hype without audience-specific need  

Hospitality itself is **not** penalized. Avoid repeated angles; allow distinct useful hospitality opportunities.

## Content format guidance

| Need | Prefer |
| --- | --- |
| Definition | Glossary |
| Ordered steps | Checklist |
| Platform trade-offs | Comparison |
| Deep process / decision | Guide or Insight |
| Service catalogue | Service page update |
| Product changelog impact | Platform page ± supporting Insight |

Insight must not win by default merely because discovery lives in AI Writer.

## Refresh strategy

Strong refresh:

- Facts, workflows, or platform guidance changed  
- Examples/screenshots outdated  
- Page no longer fits site architecture  

Weak refresh:

- “Article is N months old” alone  

## Suggested 90-day slate shape (recommendation only)

Broaden authority while keeping selective industry depth:

1. Redesign vs rebuild (decision)  
2. Migration without ranking loss (process)  
3. Core Web Vitals for business owners (performance)  
4. Traffic vs enquiries / KPI framing (conversion)  
5. Local SEO for service businesses  
6. Trust signals on service sites  
7. Shopify vs BigCommerce (or refresh existing comparison)  
8. How to brief an agency  
9. Selective hospitality piece only if distinct from archive  
10. Refresh any Comparison/Checklist proven stale by official sources  

Cadence is editorial choice — not a hard-coded quota.

## Sequencing

- Publish or refresh broad foundations before narrow debugging pieces  
- Update Comparisons before Insights that lean heavily on them  
- Prefer SUPPORT_COMMERCIAL_PAGE when Services/Solutions already own the offer  

## Admin ownership

The slate remains a recommendation. Admin approves backlog items and chooses AI Editorial Project handoff. No auto-write / auto-publish.
